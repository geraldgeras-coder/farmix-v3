# FARMIX Theme Reference

The exact splash artwork is included at:

`app/src/main/res/drawable/farmix_splash_logo.png`

Use this image directly for the FARMIX splash/loading screen. Do not recreate, reinterpret, redraw, recolor, or replace it with a different generated design.

The desired visual identity is:

- dark cinematic forest-green background
- premium gold and leaf-green highlights
- cream/gold FARMIX lettering
- tagline: `Smart Feed. Better Growth.`
- polished agricultural/feed brand feeling

If changing the app UI, keep colors and graphics consistent with this image.
